# Contributing

Thanks for your interest in improving Vision Cursor!

## Cursor assets

- Keep black cursor files in `Black/` and white cursor files in `White/`.
- Use clear filenames that describe the pointer role, and keep the existing `.cur` and `.ani` formats.
- Include attribution and source information when available.
- Only submit assets you have the right to distribute; do not assume files found online are free to reuse.

## Proposing a change

Open a pull request with a short description of the change. For new or replaced cursor files, identify the affected variant and pointer role, and include source or permission details where possible.

## Testing

There is no build or automated test process for this asset collection. Before submitting, check that the files open and can be selected in Windows pointer settings.

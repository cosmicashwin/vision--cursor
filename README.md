# Vision Cursor

A Windows cursor theme collection with two variants: **Black** and **White**. Cursor assets are stored in the [`Black/`](Black/) and [`White/`](White/) folders.

## Cursor files

The folders contain Windows cursor (`.cur`) and animated cursor (`.ani`) files. The filenames describe common pointer roles, such as `pointer`, `text`, `help`, and `busy`.

## Install on Windows

1. Download or clone this repository to your computer.
2. Open **Settings** and search for **Mouse pointer** or **Additional mouse settings**. Depending on your Windows version, you can also open **Control Panel → Mouse → Pointers**.
3. In the **Pointers** tab, select a pointer role and choose **Browse…**.
4. Select the matching `.cur` or `.ani` file from either `Black/` or `White/`. Repeat for the pointer roles you want to customize.
5. Choose **Save As…** to save the scheme, then select **Apply**.

To restore the standard pointers, select the Windows default scheme and apply it.

## Contributing
